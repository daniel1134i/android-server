## 1. Обзор системы и архитектура

Комплекс превращает Android-планшет в полноценный, энергоэффективный микро-сервер домашней или офисной автоматизации, который работает круглосуточно без перехода в глубокий сон.

```
┌─────────────────────────────────────────────────────────────┐
│                 macOS Controller Desktop App                │
│         (Pixel Art × Claude Code UI / Dark Theme)           │
│  - Телеметрия железа (CPU, RAM, Батарея, Температура)        │
│  - Удаленный шелл, файловый менеджер, деплой программ       │
│  - Управление экраном, Wakelock и журналы аудита            │
└──────────────┬──────────────────────────────┬───────────────┘
               │                              │
     Прямой HTTP / Wi-Fi                 Облачный WebSocket
     или USB adb-forward                 (Шифрованный туннель
     http://192.168.x.x:8080             для доступа из любой
     http://127.0.0.1:8080               точки мира без белого IP)
               │                              │
               │                   ┌──────────▼──────────┐
               │                   │  Cloud Relay Node   │
               │                   │  (Node.js / WS RPC) │
               │                   └──────────┬──────────┘
               │                              │
┌──────────────▼──────────────────────────────▼───────────────┐
│               Android Autonomous Host Node                  │
│       (Xiaomi Redmi Pad SE / 8 ядер / Android 15)           │
│  - Foreground Service + Partial WakeLock (24/7 работа)      │
│  - Многопоточный HTTP-сервер на порту 8080                  │
│  - Фоновый Cloud Relay Client (авто-реконнект)              │
│  - AppManager: песочница /sdcard/ServerApps/                │
│  - Собственный веб-интерфейс на экране планшета:            │
│      [01 МОНИТОРИНГ] и [02 ПРИЛОЖЕНИЯ]                      │
└─────────────────────────────────────────────────────────────┘
```

## 2. Установка и запуск на Android-планшете

### Требования и первоначальная настройка
- Планшет под управлением Android 8.0 — 15 (протестировано на Xiaomi Redmi Pad SE, Android 15 HyperOS).
- Включенный режим разработчика: `Настройки` → `О телефоне/планшете` → нажмите 7 раз по `Версия ОС`, затем перейдите в `Расширенные настройки` → `Для разработчиков` → включите **Отладка по USB** (и **Установка через USB** для Xiaomi).

### Установка приложения
1. Готовый APK файл находится прямо в корне проекта: [`AndroidServer.apk`](file:///Users/daniel/Documents/проекты/%20android%20server/AndroidServer.apk).
2. Подключите планшет по кабелю к компьютеру и установите APK:
   ```bash
   adb install -r AndroidServer.apk
   ```
3. Приложение также можно передать на планшет через мессенджер, флешку или браузер и установить вручную.

### Выдача критически важных разрешений
При первом запуске приложение запросит необходимые системные привилегии:
1. **Уведомления (Notifications)**: необходимо для работы постоянного `Foreground Service` (уведомление висит в шторке, предотвращая закрытие сервера системой).
2. **Доступ ко всем файлам (Manage External Storage)**: необходимо для создания рабочей директории `/sdcard/ServerApps` и сохранения загруженных файлов и баз данных.
3. **Игнорирование оптимизации батареи (Doze Whitelist)**: приложение автоматически откроет системное окно с предложением отключить ограничения батареи. Выберите **«Без ограничений»**. Это гарантирует, что система не усыпит процессор и сеть через несколько часов простоя.

### Автозапуск сервера при перезагрузке (BootReceiver)
В манифесте зарегистрирован компонент `BootReceiver`. Если планшет перезагрузится (например, при обновлении системы или кратковременном отключении питания), служба `ServerService` запустится **автоматически в фоновом режиме** без необходимости открывать приложение вручную.

## 3. Подключение к серверу и авто-связывание

### ⚡ Способ 0: АВТО-СВЯЗЫВАНИЕ В 1 КЛИК (Рекомендуемый, самый простой)
Больше не нужно вручную искать IP-адрес или копировать секретные ключи:
1. Запустите приложение на планшете и на компьютере Mac (оба устройства должны быть подключены к одной сети Wi-Fi).
2. В приложении Mac Controller нажмите кнопку **`⚡ 1-КЛИК АВТО-СВЯЗЫВАНИЕ`** (в боковом меню или на вкладке «Подключение»).
3. Компьютер мгновенно найдет планшет (через параллельный опрос UDP 8081, mDNS и сканирование подсети), безопасно запросит защищенные E2E-ключи и **свяжет устройства навсегда**.
4. Все параметры доступа сохранятся автоматически, и включится облачный канал Cloud Relay.
5. **Готово!** Теперь вы можете отключить Wi-Fi, уехать в другой город за 1000 км — Mac будет подключаться к планшету автоматически через интернет.

---

### Другие способы подключения (ручные/резервные):

#### Способ 1: Локальная сеть Wi-Fi (прямое подключение)
Планшет и компьютер находятся в одной беспроводной сети (домашний или офисный роутер).
- На экране планшета в шапке отображается его текущий IP-адрес: например, `http://192.168.0.82:8080`.
- В приложении на Mac на вкладке **«ПОДКЛЮЧЕНИЕ»**:
  - Нажмите кнопку **`Wi-Fi планшета (192.168.0.82:8080)`** или **`🔍 АВТО-ПОИСК (MDNS)`**.
  - Нажмите **`СОХРАНИТЬ И ПОДКЛЮЧИТЬСЯ`**.
- В браузере любого устройства в домашней сети можно открыть этот же адрес: `http://192.168.0.82:8080` и получить доступ к веб-панели управления планшетом.

#### Способ 2: USB-кабель через ADB туннель (резервный/проводной)
Если Wi-Fi роутер временно отключился или связь нестабильна, подключите кабель Type-C:
- В приложении на Mac нажмите **`⚡ USB ADB ТУННЕЛЬ`** или кнопку быстрого пресета **`USB ADB (127.0.0.1:8080)`**.
- Приложение выполнит команду `adb forward tcp:8080 tcp:8080`.
- Трафик пойдет напрямую по медному кабелю на скорости шины USB с нулевой задержкой.

#### Способ 3: Ручная настройка Cloud Relay
Для тех, кто хочет вручную контролировать параметры облачного туннеля:
- На экране планшета нажмите на синий чип **`☁ ОБЛАКО (ID) node_xxxxxxxx`** — отобразится ваш `Node ID` и `Secret Key`.
- В Mac Controller на вкладке «Подключение» введите эти значения и нажмите **`☁ ПОДКЛЮЧИТЬСЯ ЧЕРЕЗ ОБЛАКО`**.

#### ⚠️ Сброс соединения к заводским настройкам (с нуля)
Если требуется перепривязать планшет, очистить сессии или начать с чистого листа:
- В Mac Controller перейдите на вкладку **«07 ПОДКЛЮЧЕНИЕ»**.
- В блоке «Сброс соединения и параметров» нажмите **`🗑 СБРОСИТЬ ВСЕ НАСТРОЙКИ С НУЛЯ`** и подтвердите действие.
- Приложение автоматически разорвет все сетевые соединения, очистит локальный кэш и вернется к заводскому состоянию первого запуска.

## 4. Работа с интерфейсом на самом планшете

Экран планшета оснащен полнофункциональной сенсорной консолью управления.

### Вкладка 01: МОНИТОРИНГ
- **Мастер-карточка**:
  - Светодиодный индикатор активности демона.
  - Сетевые адреса (Wi-Fi, USB 127.0.0.1, Cloud Relay ID).
  - Интерактивный чип `ПРИЛОЖЕНИЯ: X активных ↗` (нажатие на него мгновенно открывает вкладку приложений).
  - Кнопка принудительной остановки/запуска демона.
  - Кнопка включения режима `OLED ЭКО`.
- **Карточки телеметрии**:
  - **Батарея и температура**: точный заряд %, температура с шагом 0.1°C, источник питания (AC/USB) и здоровье аккумулятора.
  - **ОЗУ и процессор**: использование памяти в ГБ, нагрузка %, количество ядер и архитектура.
  - **Накопитель и аптайм**: занятое и свободное место на диске, время непрерывной работы демона и общее время работы Android.
- **Журнал событий (Audit Stream)**: лог сетевых обращений, входящих HTTP-запросов и системных сообщений в реальном времени.

### Вкладка 02: ПРИЛОЖЕНИЯ
Позволяет развертывать, запускать и контролировать программы прямо пальцем на сенсорном экране:
- **Переключатель типа деплоя**: `🌐 GIT РЕПОЗИТОРИЙ` или `📦 ZIP АРХИВ`.
- **Поля ввода**:
  - Git URL / выбор ZIP-файла на планшете.
  - Имя папки приложения.
  - Команда запуска (например, `python3 main.py` или `node server.js`).
  - Кнопка **`🚀 ЗАГРУЗИТЬ И ЗАПУСТИТЬ`**.
- **Сетка развернутых микросервисов**:
  - Для каждого приложения отображается статус (`● ЗАПУЩЕНО` зеленым или `○ ОСТАНОВЛЕНО`), путь, PID процесса, аптайм и исполняемая команда.
  - Кнопки **`▶ ЗАПУСТИТЬ`** / **`⏻ ОСТАНОВИТЬ`**.
  - Кнопка **`📋 ЛОГИ`** — открывает модальное окно с выводом терминала данного микросервиса.
  - Кнопка **`🗑 УДАЛИТЬ`** — удаление приложения с диска планшета.

### Энергосберегающий режим OLED ЭКО
При нажатии на кнопку **`🌙 OLED ЭКО (ЭКОНОМИЯ 95%)`**:
- Яркость экрана снижается до абсолютного физического минимума (1 nit).
- Экран заливается глубоким черным цветом, что на современных AMOLED/IPS экранах снижает потребление энергии дисплеем более чем на 90% и исключает нагрев.
- Сервер продолжает работать на полную мощность. Повторное нажатие восстанавливает нормальную яркость.

## 5. Работа через настольное приложение macOS

Настольное приложение [`AndroidServerController.app`](file:///Applications/AndroidServerController.app) представляет собой центр управления сервером с расширенными инструментами разработчика.

### Вкладки и возможности Mac Controller:
- **01 ТЕЛЕМЕТРИЯ**: дашборд состояния хост-ноды, график памяти, прогресс-бар заряда батареи с цветовой индикацией безопасной зоны 20-80%.
- **02 ТЕРМИНАЛ**: полноценная удаленная командная строка. Поддерживает выполнение любых консольных команд (`ls -la`, `ps -ef`, `df -h`, `uname -a`, `cat`, запуск скриптов).
- **03 ФАЙЛЫ**: удаленный файловый браузер. Позволяет перемещаться по файловой системе планшета, просматривать размеры файлов, переходить по папкам и скачивать любые файлы на Mac в один клик.
- **04 ПРИЛОЖЕНИЯ**: мощный инструмент деплоя микросервисов из репозиториев GitHub или локальных ZIP-архивов с Mac на планшет.
- **05 ЛОГИ**: поток аудита всех запросов к серверу с фильтрацией по ключевым словам (`GET`, `POST`, `ERROR`), кнопками паузы потока и копирования.
- **06 ПИТАНИЕ И ЭКО**: рекомендации по сохранению ресурса литиевой батареи, безопасные температурные пороги, управление экраном.
- **07 ПОДКЛЮЧЕНИЕ**: переключение между Wi-Fi, USB и Cloud Relay, настройка ключей авторизации, статус ADB.

## 6. Развертывание (деплой) приложений и микросервисов

Все развернутые программы изолированно хранятся в директории `/sdcard/ServerApps/<имя_приложения>/`.

### Способ деплоя 1: Git-репозиторий (GitHub / GitLab)
1. Откройте вкладку **«ПРИЛОЖЕНИЯ»** (на планшете или на Mac).
2. Выберите режим **`🌐 GIT РЕПОЗИТОРИЙ`**.
3. Вставьте URL репозитория:
   - Публичный: `https://github.com/username/my-microservice`
   - Приватный с токеном в поле: введите `Personal Access Token` в поле токена.
   - Или укажите токен прямо в URL: `https://ghp_xxxx@github.com/username/my-microservice.git`
4. Введите имя приложения (или оставьте авто-заполнение).
5. Нажмите **`🚀 ЗАГРУЗИТЬ И ЗАПУСТИТЬ`**.
6. Сервер на планшете скачает ZIP-архив репозитория через GitHub API / архивную ветку, распакует файлы, назначит права на исполнение (`chmod +x`) и запустит сервис.

### Способ деплоя 2: Локальный ZIP-архив
1. Запакуйте исходники вашего проекта в стандартный `.zip` архив.
2. Выберите режим **`📦 ZIP АРХИВ`**.
3. Нажмите **`📁 ВЫБРАТЬ ZIP ФАЙЛ`** и укажите архив.
4. Нажмите **`🚀 ЗАГРУЗИТЬ И ЗАПУСТИТЬ`**.
5. Приложение закодирует архив, передаст его на планшет (по Wi-Fi, USB или через Cloud Relay) и автоматически распакует в `/sdcard/ServerApps/<имя_папки>/`.

### Автозапуск и скрипты запуска (start.sh, main.py, index.js)
Если поле «Команда запуска» оставлено пустым, `AppManager` автоматически определит точку входа по следующим правилам приоритета:
1. Если есть файл `start.sh` → выполнит `sh start.sh`
2. Если есть файл `run.sh` → выполнит `sh run.sh`
3. Если есть `main.py` → выполнит `python3 main.py` (или `python main.py`)
4. Если есть `app.py` → выполнит `python3 app.py`
5. Если есть `index.js` или `server.js` → выполнит `node index.js` / `node server.js`
6. Если есть `bot.py` → выполнит `python3 bot.py`
7. Если ничего из этого нет → запустит первый исполняемый `.sh` файл.

> **Совет**: Создайте в корне вашего проекта простой скрипт `start.sh`:
> ```bash
> #!/bin/sh
> echo "Запуск сервиса..."
> python3 main.py >> app.log 2>&1
> ```

### Просмотр логов приложений в реальном времени
- Весь вывод программы (`stdout` и `stderr`) автоматически перенаправляется и пишется в файл `app.log` внутри папки приложения.
- Нажмите кнопку **`📋 ЛОГИ`** на карточке приложения:
  - Откроется окно с выводом логов.
  - Встроена автоматическая ротация логов (файл не разрастется больше 3 МБ, сохраняя место на диске планшета).

## 7. Безопасность и многопользовательская изоляция

Система спроектирована для безопасного использования несколькими независимыми пользователями:

### Защита Cloud Relay (Node ID + Secret Key)
1. **Строгая изоляция клиентов**: Каждая хост-нода генерирует уникальный криптографический идентификатор (`node_xxxx`) и 32-байтный секретный ключ (`sec_xxxx`), которые хранятся локально в защищенном хранилище планшета (`EncryptedSharedPreferences`).
2. **Нулевой доступ чужих пользователей**: Даже зная публичный адрес Cloud Relay сервера, ни один посторонний пользователь не сможет подключиться к чужой ноде без знания ее секретного ключа. Сервер релея маршрутизирует трафик только при совпадении токена авторизации.
3. **Поддержка нескольких контроллеров**: К одной ноде можно одновременно безопасно подключать несколько устройств (например, ваш рабочий Mac и домашний ноутбук) — сессии не конфликтуют и не выбивают друг друга.

### Защита от атак (Zip Slip, Path Traversal, Shell Injection)
- **Защита от Zip Slip**: Алгоритм распаковки архивов проверяет канонический путь каждого распаковываемого файла (`canonicalPath.startsWith(appFolder)`). Попытка создать файл за пределами выделенной папки немедленно пресекается.
- **Санитарная очистка имен**: Имена приложений и папок фильтруются регулярным выражением `[^a-zA-Z0-9._-]`. Невозможно передать символы `../`, пробелы или команды внедрения оболочки.

## 8. Круглосуточная работа 24/7 и защита аккумулятора

Планшет оснащен литий-ионным/полимерным аккумулятором. Непрерывное нахождение на зарядке при 100% в течение месяцев может вызвать деградацию лития.

### Рекомендации по сохранению аккумулятора:
1. **Эко-диапазон 20% — 80%**:
   - Приложение выводит цветовую шкалу: зеленый цвет (оптимально), оранжевый (рекомендуется отключить зарядное устройство).
2. **Использование умной Wi-Fi розетки**:
   - Самый надежный способ для работы 24/7 годами: подключить адаптер питания планшета через умную розетку (Tuya, Яндекс, Sonoff, Zigbee).
   - Настроить автоматизацию: включать розетку при падении заряда до 25% и выключать при достижении 80%. В таком режиме батарея планшета прослужит 5–7 лет без потери емкости и риска вздутия.
3. **Температурный мониторинг**:
   - Встроенный термо-монитор следит за температурой батареи с частотой опроса 1 раз в секунду. Если температура превысит 42°C, система выведет предупреждение.

## 9. Диагностика и решение возможных проблем (Troubleshooting)

### Планшет отображает статус «ОФЛАЙН» при отключении кабеля
- **Причина**: Компьютер был подключен через USB ADB туннель (`127.0.0.1:8080`). При извлечении кабеля туннель ADB физически разрывается.
- **Решение**: В приложении на Mac нажмите на кнопку пресета **`Wi-Fi планшета (192.168.0.82:8080)`** или **`☁ ОБЛАКО (RELAY)`**. Сервер мгновенно продолжит отвечать по беспроводному каналу.

### Сервер заснул после отключения экрана на несколько часов
- **Причина**: На планшете активен режим агрессивного энергосбережения MIUI / HyperOS.
- **Решение**:
  1. Перейдите в `Настройки` → `Приложения` → `Android Server` → `Контроль активности`.
  2. Выберите режим: **«Нет ограничений»** (No restrictions).
  3. В меню запущенных приложений нажмите и удерживайте карточку `Android Server` и нажмите на значок **Замка** (Lock), чтобы система никогда не выгружала процесс из памяти.

### Ошибка «Permission denied» при попытке деплоя
- **Причина**: Планшет не предоставил доступ к хранилищу.
- **Решение**: Перейдите в `Настройки` → `Приложения` → `Android Server` → `Разрешения` → `Файлы и медиаконтент` → выберите **«Разрешить управление всеми файлами»**.
